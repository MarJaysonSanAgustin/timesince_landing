# TimeSince

**TimeSince** is a landing page for a premium, privacy-focused, local-first application designed to help you track your life's natural rhythm. In a world obsessed with rigid schedules and daily streaks, TimeSince focuses entirely on the interval—the time since a task or habit was last done.

## Features

- **Dynamic Event Customization:** Customize events using premium color palettes, intuitive emojis, and custom image covers.
- **Advanced Custom Logging:** Define custom inputs for each event, such as numbers for doses, text fields for detailed journaling, or photos for visual evidence.
- **Privacy-First Hidden Events:** Keep sensitive habits confidential with a dedicated hidden layer shielded by biometric security and encrypted locally.
- **Rhythm Analytics:** Analyze your logging history to calculate average intervals, categorize events by frequency, and view beautiful dynamic charts displaying interval trends over time.
- **A Beautiful Timeline:** Keep your habits, events, and routines organized in a stunning timeline.

## Tech Stack

This project is built using:
- **Next.js 15**
- **React 19**
- **Tailwind CSS v4**
- **Lucide React** (Icons)
- **Motion** (Animations)

## Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
