## Availability questions

- Apple confirms goals and the widget preview gallery. The public notes do not separately identify the goal widget, the Attempts page or the exact build carrying individual refinements. These details need a version-matched public reference or a check on the distributed app before advertising them.
- Apple confirms improved backups and a duplicate Siri log fix. The exact backup verification procedure and retention windows are implementation details. The website makes no retention-period guarantee.
- No installed App Store build was exercised in this review. The app source shows explicit unarchiving and retains archived history. Automatic bulk unarchiving on resubscription has no release confirmation. The website describes the manual action.
- The timer reference explicitly lists Siri/NFC timer control and an away-from-app timer-end notification as unbuilt. Ordinary Siri/NFC logging and the released Lock Screen timer controls are separate actions.
- The US storefront confirms monthly, annual and lifetime pricing. Trial eligibility, regional offers and remote paywall settings were outside the available evidence.
